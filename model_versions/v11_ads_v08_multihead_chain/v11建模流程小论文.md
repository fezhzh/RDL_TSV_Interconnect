# 基于 ADS 单器件仿真与显式连接网络的 RDL-TSV 长链结构频域建模方法

## 摘要

复杂三维互连结构的频域 S 参数建模通常依赖全波电磁仿真，但当结构由多段 RDL 与 TSV 级联构成时，直接对整体结构进行大规模参数扫描会带来较高的计算成本。Ye 等人在 2026 年提出的 assemble neural network 思路将复杂互连拆分为可复用子结构模型，先通过子结构 S 参数级联得到粗模型，再用 coupling neural network 将粗级联结果映射到全结构精确响应。受这一思想启发，本文针对 `v11_ads_v08_multihead_chain` 中的 RDL-TSV 长链结构，提出一种更偏电路可解释的混合建模流程：使用 ADS 对 TMRDL、BSMRDL 和 TSV 单器件进行快速仿真，以 ABCD 矩阵完成 13 个器件块的级联，并在 12 个 RDL/TSV 连接位置插入七参数 pi 型连接网络，以显式电路参数补偿单器件级联与 HFSS 全结构目标之间的耦合误差。进一步地，本文采用“共享连接优化-正参数约束-多头神经网络-物理约束诊断”的分阶段训练策略，将结构几何参数映射到连接网络参数，再由级联电路生成整体 S 参数。当前 v11 结果表明，正参数共享连接优化可将 298 个当前可用 LHS400 样本上的平均 NMSE 从 ADS 直接级联的 0.453240 降至 0.0279288；在神经网络预测阶段，正参数多头 S 参数训练可将共享网络展开后的 NN 均值误差从 0.343877 降至 0.0532449，并在 294/298 个样本上优于直接级联。该方法继承了 assemble NN 的“子结构复用与粗到细修正”思想，同时用显式 pi 型网络替代纯黑箱 coupling network，增强了连接界面建模的可解释性和可诊断性。

**关键词：** RDL；TSV；ADS；HFSS；assemble neural network；S 参数级联；pi 型连接网络；多头神经网络；三维集成

## 1. 引言

随着三维集成和先进封装技术的发展，TSV、RDL 以及二者之间的过渡连接成为高速信号通道中的关键互连单元。高频下，互连结构的寄生电容、电感、电阻损耗和连接界面不连续性会共同影响反射、插入损耗和相位延迟。因此，在设计阶段快速获得结构参数到宽频 S 参数的映射，对信号完整性分析和结构优化具有直接意义。

传统方法通常使用 HFSS 等全波电磁仿真工具直接求解完整三维结构。这类方法精度高，但对于包含多个基本器件和多个连接界面的长链结构，仿真代价会随样本数和结构复杂度迅速增加。另一类方法是直接训练神经网络从几何参数预测整体 S 参数，但这种端到端黑箱模型需要大量全结构仿真数据，且不容易解释误差来自单器件响应、级联顺序还是连接界面耦合。

Ye 等人的 assemble neural network 方法提供了一个重要启发：复杂结构不应总是作为一个整体黑箱建模，而可以先拆分为基本子结构，用可复用子结构网络预测各部分 S 参数，再按物理拓扑级联得到粗模型，最后用一个 coupling network 学习粗模型到精细 HFSS 响应之间的映射。该框架的关键价值在于复用已有子结构模型，并利用粗级联 S 参数作为高信息量输入，从而减少复杂全结构样本需求。

本文研究的 v11 RDL-TSV 长链结构也符合这一问题特征。目标拓扑为：

```text
TMRDL-TSV-BSMRDL-TSV-TMRDL-TSV-BSMRDL-TSV-TMRDL-TSV-BSMRDL-TSV-TMRDL
```

该结构包含 13 个单器件块和 12 个连接位置。若仅使用 ADS 或神经网络分别预测 TMRDL、BSMRDL、TSV 的单器件 S 参数，再简单级联，模型会忽略连接处局部耦合和不连续效应。若直接训练整体结构代理模型，又会丢失单器件仿真和电路级联的物理先验。基于此，本文采用 ADS 单器件仿真作为可复用基本模型，以 ABCD 级联作为粗模型，并将 Ye 等人框架中的 coupling correction 显式化为可优化的 pi 型连接网络。这样，粗到细修正不再完全由黑箱 CNN/TCNN 完成，而是由具有电路意义的连接网络参数承担。

本文的主要内容包括：

1. 建立面向 13 块 RDL-TSV 长链的 ADS 单器件级联模型。
2. 在 12 个连接处插入七参数 pi 型网络，构造可解释的连接耦合修正。
3. 通过逐样本优化获得共享连接网络参数，并用正参数约束提升物理合理性。
4. 训练结构参数到连接网络参数的神经网络，再扩展为多头和对称多头结构。
5. 结合 S11/S21 实部、虚部、相位、L/C 范围和局部谐振频率诊断模型误差。

## 2. 参考论文方法及其对本文的启发

Ye 等人的方法将 assemble NN 分为四个核心环节：Reusable Lego NN，S-parameter Cascading Model，Sensitivity Analysis based training set screening，以及 Coupling NN。其思想可以概括为“先分解、再级联、后修正”。

Reusable Lego NN 用于学习单个基本子结构从几何参数到 S 参数的映射。对于互易二端口网络，论文只需建模 S11 和 S21 的实部与虚部，其余项可由互易性推得。这样，低维几何参数被映射为高维频域曲线。Ye 等人使用 TCNN 作为示例网络，因为 S 参数频率曲线可以被视为类似图像的高维矩阵，转置卷积适合完成低维到高维的上采样映射。

S-parameter Cascading Model 负责把各子结构 S 参数转换为 ABCD 矩阵，并按实际结构顺序相乘，再转换回整体 S 参数。该步骤是 assemble NN 的物理骨架：它保证模型不是任意拼接曲线，而是遵循二端口网络级联关系。矩阵相乘不满足交换律，因此器件顺序必须与真实拓扑一致。

Coupling NN 用于处理粗级联模型与 HFSS 全结构结果之间的偏差。Ye 等人指出，单器件级联与整体仿真结果通常具有较相似的曲线形态，但由于连接处耦合和不连续效应，二者在实部、虚部和相位上仍会存在偏移。CONN 通过一维卷积编码器和转置卷积解码器学习高维 S 参数曲线到高维 S 参数曲线的映射，相当于将粗模型修正为精细模型。

Sensitivity Analysis based screening 则解决小样本训练时训练集分布不完整的问题。论文先用子结构模型做 Sobol 敏感性分析，并结合小波变换提取 S 参数曲线特征，再按照高敏感输入参数筛选训练样本，使 CONN 在较少全结构仿真数据下仍能覆盖关键曲线形态。

本文借鉴上述框架，但做出两点关键调整。第一，本文不重新训练单器件 RLNN，而是使用 ADS 作为单器件响应生成器；这相当于用可调校的电路/电磁仿真模块替代 RLNN，避免在单器件阶段再次引入神经网络误差。第二，本文不使用纯 CONN 直接修正粗级联 S 参数，而是在每个连接处插入显式 pi 型网络，将 coupling correction 转化为有电路参数的局部连接模型。神经网络学习的对象也从“粗 S 参数到精细 S 参数”变为“结构参数到连接网络参数”，最终 S 参数仍由物理级联产生。

## 3. 建模对象与数据

### 3.1 长链结构

v11 目标结构由 TMRDL、BSMRDL 和 TSV 交替级联形成，共 13 个器件块。若记连接网络为 `Conn1` 至 `Conn12`，完整模型可写为：

```text
TMRDL - Conn1 - TSV - Conn2 - BSMRDL - Conn3 - TSV - Conn4
- TMRDL - Conn5 - TSV - Conn6 - BSMRDL - Conn7 - TSV - Conn8
- TMRDL - Conn9 - TSV - Conn10 - BSMRDL - Conn11 - TSV - Conn12 - TMRDL
```

该拓扑比早期 9-block v10 结构更长，连接位置也更多，因此连接网络的稳定性和参数约束更加重要。

### 3.2 几何参数

整体结构使用 9 个主要几何输入：

```text
pitch, r_tsv, h_tsv,
l_tmrdl, w_tmrdl, t_tmrdl,
l_bsmrdl, w_bsmrdl, t_bsmrdl
```

其中 TMRDL 与 BSMRDL 分别使用自身的长度、宽度和厚度参数，TSV 使用高度、半径和 pitch。ADS helper 中 RDL 厚度字段会映射到 ADS 所需的高度参数，例如 `t_tmrdl -> h_tmrdl`。

### 3.3 数据来源

单器件 ADS 校准使用：

```text
HFSS_sim/LHS400_Connection2/train/RDL
HFSS_sim/LHS400_Connection2/train/TSV
```

长链训练与测试主要使用：

```text
HFSS_sim/LHS150_50_Connection2/train/TSV_RDL
HFSS_sim/LHS150_50_Connection2/test/TSV_RDL
```

正参数共享优化和后续多头模型进一步使用当前磁盘中已有的：

```text
HFSS_sim/LHS400_Connection2/train/TSV_RDL
```

这些 HFSS 全结构样本在本文中相当于 Ye 等人 CONN 训练所需的 fine S-parameter 数据，而 ADS 直接级联结果相当于 coarse S-parameter 数据。

## 4. 方法框架

### 4.1 ADS 单器件模型

参考 assemble NN 中 RLNN 的作用，本文首先为 TMRDL、BSMRDL 和 TSV 构建可复用单器件响应模块。区别在于，本文使用 ADS 仿真而非神经网络直接生成单器件 S 参数。这样做有两个优点：一是单器件模型仍由电磁/电路仿真工具给出，物理含义清晰；二是当器件参数变化时，可以通过 ADS cache 复用已有结果，减少重复仿真。

为了使 ADS 单器件响应与 HFSS 单器件结果一致，本文先用少量 RDL 和 TSV 样本进行校准。当前随机 30 组 RDL 与 30 组 TSV 校准结果显示，RDL 最优候选为 `w_scale=0.55`，NMSE 均值由 baseline 的 0.0442668 降至 0.0334426；TSV 最优候选为 `pitch_scale=1.1`，NMSE 均值由 0.00550278 降至 0.00533247。这一步对应参考论文中“先保证基本子结构模型可复用且足够准确”的思想。

### 4.2 ABCD 级联粗模型

得到单器件 S 参数后，模型将每个二端口网络转换为 ABCD 矩阵，并按真实拓扑顺序相乘。级联顺序必须与物理结构一致，因为 ABCD 矩阵乘法不满足交换律。级联后再将总 ABCD 矩阵转换回 S 参数，得到 ADS direct cascade。

该直接级联模型是本文的 coarse model。它包含了各单器件的频域响应和长链传播路径，但不包含连接界面处的局部不连续、过渡耦合和工艺近场影响。因此，其误差主要反映“单器件复用”与“整体结构仿真”之间的差距。

### 4.3 显式 pi 型连接网络

参考论文使用 CONN 学习 coarse S 参数到 fine S 参数的高维映射。本文则将该修正拆解到每个连接位置，用 pi 型电路表示局部 coupling correction。每个连接网络包含 7 个参数：

```text
Cn1, Rn1, Cn2, Rn2, Cn3, Rn3, Ln1
```

其 Y 参数为：

```text
Y1 = j*w*Cn1 + 1/Rn1
Y2 = j*w*Cn2 + 1/Rn2
Y3 = j*w*Cn3 + 1/(Rn3 + j*w*Ln1)
```

对应 ABCD 矩阵为：

```text
A = 1 + Y2/Y3
B = 1/Y3
C = Y1 + Y2 + Y1*Y2/Y3
D = 1 + Y1/Y3
```

该网络可看作连接处的局部并联-串联修正。`Cn1`、`Cn2` 表示两侧节点的等效容性耦合，`Rn1`、`Rn2` 表示损耗通道，`Cn3`、`Rn3`、`Ln1` 形成跨接支路，用于描述连接处频散和局部谐振趋势。与 CONN 的高维曲线修正相比，pi 网络的参数数量更少，且每个参数都能被诊断。

### 4.4 共享连接优化

初始优化阶段假设 12 个连接位置共享同一组 pi 网络参数。对于每个样本，只需优化 7 个参数，然后将同一个连接网络重复插入所有连接处。该设置降低了优化自由度，便于验证连接修正是否有效。

优化目标为最小化级联模型与 HFSS 全结构目标之间的 `S11/S21` 误差。早期 signed-parameter 版本允许 scale 参数取负，在 ADS 几何长度缩放 0.9 的设定下，good-start 继续优化后可将 200 个 `LHS150_50_Connection2` 样本的全样本 NMSE 均值降至 0.0270039，测试均值降至 0.0258311。但符号诊断显示许多最终参数为负，例如 `Cn3_scale` 有 124/200 个样本为负，`Rn3_scale` 有 176/200 个样本为负。此类结果虽然拟合较好，但物理解释性不足，也不适合作为稳定的神经网络监督目标。

因此，后续主线采用正参数约束。正参数共享优化在当前可用 `LHS400_Connection2/train/TSV_RDL` 样本上运行，先优化 280 个已有 `.s2p` 样本，再用 good-start 策略扩展到 298 个当前可用样本。最终结果为：ADS 直接级联 NMSE 均值 0.453240，正参数 good-start 共享优化均值 0.0279288，且 298/298 个样本均优于直接级联。该结果说明，显式连接网络能够有效承担参考论文中 CONN 的粗到细修正作用。

## 5. 神经网络训练策略

### 5.1 从优化参数到监督学习

逐样本优化得到的连接网络参数只能解释已有样本，不能直接预测新结构。为获得快速代理模型，需要训练神经网络实现：

```text
几何参数 -> pi 型连接网络参数 -> 级联 S 参数
```

第一阶段使用 7 个独立参数网络，每个网络对应一个 pi 参数，结构为：

```text
9 -> 30 -> 30 -> 20 -> 1
```

对于正参数流程，网络学习 `log10(parameter)`，预测后再反变换为正参数。这种处理类似于将物理约束写入输出参数化：只要 log 域输出有限，电路参数就保持正值。

然而，当前正参数 shared 7-network 结果表明，仅做参数监督还不足以复现优化级联响应。298 个样本上，优化目标 NMSE 均值为 0.0279288，而共享 NN 级联均值为 0.343877。这说明逐样本优化参数可能存在非唯一性或不平滑性，单纯让网络拟合参数不一定能得到最好的 S 参数。

### 5.2 多头 S 参数微调

为提高表达能力，本文将共享参数网络扩展为 12 个连接位置 head。每个 head 输出 7 个参数，因此总输出维度为：

```text
12 * 7 = 84
```

多头网络保留共享 trunk 来提取几何特征，不同 head 对应不同连接位置的局部修正。训练时以共享正参数网络为初始化，再以级联后的 `S11/S21` 实部和虚部为主要目标进行端到端微调。该阶段与参考论文 CONN 的目标相似，都是缩小 coarse model 与 HFSS fine model 的差距；但本文的修正仍通过电路参数和 ABCD 级联完成，而不是直接输出修正后的 S 参数曲线。

当前正参数多头 S 参数训练结果显示，全样本 NN NMSE 均值从共享展开 baseline 的 0.343877 降至 0.0532449，验证均值从 0.399673 降至 0.0562088。该模型在 294/298 个样本上优于直接级联，并且所有 3576 个预测多头参数均保持正值。

### 5.3 物理约束与谐振诊断

参考论文强调 S 参数输出需要满足物理一致性，包括因果性和无源性。本文当前没有直接在输出 S 参数上加入 Hilbert transform 或 SVD hard constraint，而是从连接网络参数空间施加物理约束与诊断，重点抑制非物理 L/C 极值和局部谐振。

未加强约束的正参数多头模型中，部分样本出现 resonance-like 尖峰。诊断发现主要极端输出来自电容参数，尤其是 `Cn3_scale`；其 p99 可达到 11626.8，最大值达到 84489.8。随后加入 L/C 软约束，将 `Cn*_scale < 1000` 和 `Ln1_scale < 1000` 写入损失函数，使全样本 NN NMSE 改善至 0.0473491，验证均值改善至 0.0468867，同时 `Cn3_scale` 最大值降至 1752.3。

进一步 strong-LC 约束可减少谐振样本，但会牺牲部分平均误差。这说明连接网络的物理稳定性不能只依靠 NMSE 判断，还需要结合参数范围、频率响应平滑性和局部谐振位置综合评估。

### 5.4 对称多头结构

v11 长链拓扑具有近似左右对称性。基于这一结构先验，本文进一步将 12 个 head 折叠为 6 个独立 head，并按如下顺序镜像：

```text
1,2,3,4,5,6,6,5,4,3,2,1
```

对称多头相当于用结构先验筛掉不必要的自由度，避免每个连接位置独立漂移。当前对称六头 L/C 模型在原始谐振判据下将 resonance-like 样本数降至 0/298；较低阈值统计也明显改善。其全样本 NN NMSE 为 0.0528428，略差于 L/C-limited 多头的 0.0473491，但优于 strong-LC 模型的 0.0582432。该结果说明，与单纯加强惩罚项相比，利用拓扑对称性是更稳定的物理约束方式。

## 6. 误差指标与训练目标

本文与参考论文一样，主要使用 `S11` 和 `S21` 的实部、虚部进行训练和评价。对于互易二端口结构，`S11/S21` 已能覆盖主要反射和传输响应。常用 NMSE 定义为：

```text
NMSE = sum((y_true - y_pred)^2) / sum((y_true - mean(y_true))^2)
```

其中 `y` 可以由 `Re(S11)`、`Im(S11)`、`Re(S21)` 和 `Im(S21)` 拼接得到。该指标能够衡量整条频率曲线的归一化误差，适合比较直接级联、优化连接网络和神经网络预测之间的差异。

除了实部/虚部，本文还对幅值和相位进行诊断。相位误差尤其重要，因为参考论文也指出粗级联模型和精细模型有时在曲线形态上接近，但会出现相位偏移。本文后续实验加入 wrapped phase loss：

```text
phase_error = angle(pred * conj(target))
```

不过，当前 v11 结果显示，单纯增加全局相位损失并不能解决所有样本。例如 `dut72` 中，对称模型的 S11 相位在约 25 GHz 后进入不同 unwrapped phase 分支。参数消融表明，该问题主要由 C/L 支路位置决定：模型预测的 `Cn3/Ln1` 局部谐振频率约为 41-59 GHz，而优化共享目标约为 112 GHz。替换 `Cn3_scale + Ln1_scale` 可显著改善 NMSE，替换所有 C 参数加 `Ln1_scale` 则可接近优化目标。这说明相位误差的根源仍应回到连接网络参数和局部谐振位置上处理。

## 7. 与 Ye 等人 assemble NN 的关系

本文方法与 Ye 等人 assemble NN 在总体思想上是一致的：二者都避免直接用一个黑箱模型学习完整复杂结构，而是先利用基本子结构建立粗模型，再学习粗模型与精细响应之间的差异。

二者的对应关系如下。

| Ye 等人 assemble NN | 本文 v11 方法 |
| --- | --- |
| RLNN 预测单器件 S 参数 | ADS 仿真 TMRDL、BSMRDL、TSV 单器件 S 参数 |
| SCM 用 ABCD 矩阵级联子结构 | 用 ABCD 矩阵级联 13 个器件块和 12 个连接网络 |
| CONN 将粗级联 S 参数映射为精细 S 参数 | pi 型连接网络显式补偿连接耦合，NN 预测连接参数 |
| SA 筛选小样本训练集 | 当前使用优化质量筛选、resonance 诊断和物理参数约束 |
| 物理一致性 hard constraint 约束 S 参数 | 正参数、L/C 范围、f0 和对称 head 约束连接网络 |

主要区别在于修正模块的表达形式。Ye 等人的 CONN 是高维曲线到高维曲线的 encoder-decoder 网络，表达能力强，但内部修正过程较难解释。本文将修正过程转化为 12 个局部 pi 电路网络，虽然表达能力受到电路拓扑限制，但每个参数都有明确诊断意义，也更容易结合正参数、L/C 上限和拓扑对称性等工程约束。

因此，本文方法可被理解为一种“电路参数化的 assemble model”：它保留了 assemble NN 的子结构复用和粗到细建模思想，但将 coupling correction 从直接 S 参数曲线修正改为连接处电路参数修正。

## 8. 实验结果与讨论

### 8.1 ADS 单器件校准

随机 30 组 RDL 和 30 组 TSV 校准表明，ADS 单器件响应经过简单几何 scale 调整后已能接近 HFSS 单器件结果。RDL 校准后 NMSE 均值为 0.0334426，TSV 校准后 NMSE 均值为 0.00533247。TSV 单器件较易拟合，RDL 误差相对更大，因此后续连接网络不仅补偿连接界面，也会部分吸收 ADS RDL 与 HFSS 之间的残余误差。

### 8.2 共享连接网络优化

正参数共享连接优化是本文最重要的验证阶段。298 个当前可用 LHS400 样本中，ADS direct cascade 平均 NMSE 为 0.453240，而 good-start 正参数共享优化平均 NMSE 为 0.0279288，所有样本均优于直接级联。这说明连接处耦合误差是直接级联偏差的主要来源，且一个共享 pi 网络已经能捕捉大部分系统性修正。

### 8.3 神经网络预测

七个独立参数网络只能得到有限效果，因为优化参数本身可能不唯一。多头 S 参数微调显著改善了这一问题，使 NN 预测的平均 NMSE 降至 0.0532449，并在 294/298 个样本上优于直接级联。这表明，在连接网络参数监督之后继续以级联 S 参数为目标训练，是必要的端到端修正步骤。

### 8.4 物理稳定性

多头模型的主要风险是自由度过高导致局部非物理谐振。L/C 约束可降低电容极值，对称六头结构进一步压缩自由度，并将原始强谐振样本数降至 0/298。该结果与参考论文强调物理一致性的观点一致：频域代理模型不能只追求平均误差，还必须避免产生不适合后续信号完整性分析的非物理曲线。

## 9. 结论

本文参考 Ye 等人 assemble neural network 的建模思想，对 v11 RDL-TSV 长链结构建立了一套基于 ADS 单器件仿真和显式 pi 型连接网络的频域建模流程。该流程首先利用 ADS 生成可复用单器件 S 参数，再通过 ABCD 矩阵构建直接级联粗模型；随后在连接处插入 pi 网络，以逐样本优化获得连接耦合修正；最后训练神经网络从几何参数预测连接网络参数，并通过多头、正参数、L/C 约束和对称性约束提升模型精度与稳定性。

与参考论文中的 CONN 相比，本文方法的特点是将粗到细修正显式参数化为连接电路，使误差来源更容易诊断，也便于加入物理约束。当前实验表明，正参数共享连接优化已能显著降低 ADS 直接级联误差，多头 S 参数微调进一步提升了神经网络预测能力。后续工作可重点推进三个方向：第一，补充更多完整 HFSS 长链样本，提高多头模型泛化性；第二，将 L/C/f0 约束从软惩罚发展为更稳定的硬参数化；第三，借鉴参考论文中的因果性和无源性 hard constraint，在最终 S 参数输出层增加物理一致性验证或投影，使模型更适合工程级信号完整性分析。
