# HFSS-Based Equivalent-Circuit Modeling of Long RDL-TSV Interconnect Chains With a Multi-Head Connection Network

## Abstract

This paper presents an HFSS-based compact modeling method for cascaded redistribution-layer (RDL) and through-silicon-via (TSV) interconnect structures. Scalable equivalent-circuit models are first built for individual RDL and TSV devices, and an RDL-TSV Transition Model is inserted at each junction to capture local parasitic effects. To reduce parameter ambiguity in long cascades, the transition model is trained through a shared-to-multi-head strategy: shared seven-parameter optimization is followed by a twelve-head neural network for position-dependent correction. For the TSV-RDL3 validation case, the proposed model achieves 3.1% average NMSE using 120 training samples and 58 test samples. The resulting model is compact, interpretable, SPICE-compatible, and suitable for PDK-oriented applications.

**Keywords:** RDL; TSV; HFSS; equivalent circuit; S-parameters; pi-type connection network; multi-head neural network; magnitude-phase loss; compact modeling

## 1. Introduction

Three-dimensional (3-D) integration enables high-density heterogeneous systems by vertically stacking dies and connecting them through redistribution layers (RDLs) and through-silicon vias (TSVs). As RDL-TSV interconnect chains become longer, their frequency response is no longer determined by isolated RDL or TSV sections alone. Transition discontinuities, repeated cascade errors, and phase accumulation jointly affect insertion loss, return loss, and delay behavior.

Full-wave electromagnetic simulation can accurately characterize these effects, but directly simulating every full-chain geometry in HFSS is too expensive for design-space exploration, compact-model library construction, and PDK-oriented development. Therefore, an accurate compact model with clear circuit meaning and SPICE compatibility is needed.

Existing frequency-domain models usually follow two routes. Direct neural-network S-parameter surrogates can fit sampled responses, but they have limited physical interpretability and are difficult to reuse in circuit simulation. Cascading compact models of individual devices is more interpretable, but it ignores the parasitic effects introduced at RDL/TSV transitions. For long chains, these small interface errors can accumulate into significant full-structure deviations.

This work proposes a compact modeling flow that combines HFSS-derived equivalent-circuit models for individual RDL and TSV sections with a seven-parameter pi-type RDL-TSV Transition Model. A shared-to-multi-head neural network maps device geometry to transition-model parameters for the twelve junctions in the complete chain. The resulting model keeps the physical interpretability of equivalent circuits while improving full-chain accuracy over a direct cascade of isolated single-device models.

## 2. Method

### 2.1 Overall Modeling Flow

Fig. 1 summarizes the overall modeling flow for the cascaded RDL-TSV structure. The first step is to establish equivalent-circuit models for individual RDL and TSV devices. Based on the selected circuit topologies, the element values of these equivalent circuits are extracted from HFSS-simulated S-parameters. An MLP is then trained for each device type to map the physical device parameters to the corresponding equivalent-circuit element values. In this way, scalable compact models are constructed for individual RDL and TSV sections, so that new geometries can be evaluated without repeating full-wave simulation for every single device.

After the scalable RDL and TSV models are constructed, they are used to replace the multiple RDL and TSV sections in the complete interconnect structure. At each RDL/TSV transition, a parasitic-parameter model is introduced to characterize the coupling, discontinuity, and loss caused by the physical transition between the two device types. In this work, the parasitic model is implemented as a pi-type equivalent circuit. The complete compact model is therefore formed by cascading multiple RDL models, TSV models, and RDL-TSV transition models according to the physical order of the interconnect chain. The detailed chain topology and the corresponding connection positions are discussed later.

The element values of the pi-type parasitic circuit are optimized with the full-chain S-parameters as the target, so that the cascaded compact model can match the HFSS response of the complete structure. After optimization, another MLP is trained to map the device-level geometry parameters to the optimized pi-circuit element values. The final full-chain model is therefore constructed by cascading the learned RDL model, the learned pi-type parasitic model, and the learned TSV model in the same order as the physical interconnect chain.

For a chain with many RDL/TSV junctions, directly optimizing all transition models independently introduces many circuit parameters and may lead to non-unique optimized solutions. Therefore, a two-step training strategy is used. First, the RDL-TSV transition model is optimized in a shared form, where the same seven circuit parameters are repeated at all twelve connection positions for a given sample. The shared optimized targets are then used to train an initial parameter network. Second, the network is expanded into a multi-head model with twelve output heads and trained against the full-chain S-parameter response. This strategy allows the compact model to capture position-dependent interface behavior while reducing the ambiguity of directly optimizing many independent transition circuits.

### 2.2 RDL Equivalent-Circuit Model

The RDL model is built from the equivalent-circuit topology reported in [2], as illustrated in Fig. 2. This circuit can accurately represent the frequency response of an RDL section, and its element values can be extracted conveniently from S-parameters. For each HFSS sample, the RDL S-parameters are first converted into an ABCD matrix. The characteristic impedance \(Z_c\) and propagation constant \(\gamma\) are then calculated as

$$
\begin{aligned}
[A\ B;\ C\ D] &= S_\mathrm{to\_ABCD}(S, Z_0), \\
Z_c &= \sqrt{\frac{B}{C}}, \\
\gamma &= \frac{\operatorname{acosh}((A + D)/2)}{l}.
\end{aligned}
$$

Using \(Z_c\) and \(\gamma\), the per-unit-length RLGC curves are obtained as

$$
\begin{aligned}
R &= \operatorname{Re}(\gamma Z_c), \\
L &= \frac{\operatorname{Im}(\gamma Z_c)}{\omega}, \\
G &= \operatorname{Re}\left(\frac{\gamma}{Z_c}\right), \\
C &= \frac{\operatorname{Im}(\gamma/Z_c)}{\omega}.
\end{aligned}
$$

According to the equivalent-circuit formulation, when the circuit accurately represents the RDL device response, the frequency-dependent resistance, inductance, conductance, and capacitance implied by the circuit parameters must match the RLGC curves extracted from HFSS. Therefore, the following relationships should be satisfied:

$$
\frac{R_1^2R_2+R_1R_2^2+\omega^2R_1L_2^2}
{(R_1+R_2)^2+\omega^2L_2^2}
+\frac{\omega^2L_3^2R_3}{R_3^2+\omega^2L_3^2}
\approx R(\omega).
$$

$$
L_1+
\frac{R_1^2L_2}{(R_1+R_2)^2+\omega^2L_2^2}
+\frac{L_3R_3^2}{R_3^2+\omega^2L_3^2}
\approx L(\omega).
$$

$$
\frac{\omega^2R_4C_1^2}
{1+\omega^2R_4^2(C_1+C_2)^2}
\approx G(\omega).
$$

$$
\frac{
C_1+\omega^2R_4^2C_1^2C_2+\omega^2R_4^2C_2^2C_1
}
{1+\omega^2R_4^2(C_1+C_2)^2}
\approx C(\omega).
$$

The circuit parameters can then be sequentially extracted from the RLGC curves using the following formulas:

$$
\begin{aligned}
R_3 &= R(\omega_3), \\
R_1 &= R(\omega_2) - R_3, \\
R_2 &= \frac{R_1 R(\omega_1)}{R_1 - R(\omega_1)}, \\
L_1 &= L(\omega_2), \\
L_2 &= \left(L(\omega_1) - L_1 - L_3\right)
\left(\frac{R_1 + R_2}{R_1}\right)^2, \\
L_3 &= L(\omega_3), \\
C_1 &= C(\omega_1), \\
C_2 &= \frac{C_1 C(\omega_2)}{C_1 - C(\omega_2)}, \\
R_4 &= \frac{C_1^2}{G(\omega_2)(C_1+C_2)^2}.
\end{aligned}
$$

Here, \(\omega_1\) is selected at the lowest frequency, \(\omega_3\) is selected at the highest frequency, and \(\omega_2\) is selected at an intermediate frequency. In this work, these angular frequencies are set to

$$
\begin{aligned}
\omega_1 &= 0.1 \times 10^9 \times 2\pi\ \mathrm{rad/s},\\
\omega_2 &= 20 \times 10^9 \times 2\pi\ \mathrm{rad/s},\\
\omega_3 &= 100 \times 10^9 \times 2\pi\ \mathrm{rad/s}.
\end{aligned}
$$

After the element extraction, an MLP is trained to learn the mapping from the RDL geometry parameters to the equivalent-circuit element values. In this workflow, the RDL model uses `pitch`, `length`, `width`, and `thickness` as inputs. The same generic RDL backend is used for both top-metal RDL (TMRDL) and bottom-metal RDL (BSMRDL), with each section supplying its own geometry columns.

### 2.3 TSV Equivalent-Circuit Model

The TSV model is based on the equivalent-circuit model proposed in [3], as shown in Fig. 3. This circuit includes the TSV conductor resistance and inductance, the oxide capacitance, the silicon-substrate capacitance, and the substrate loss resistance. To simplify circuit-parameter extraction, the original equivalent circuit is transformed into the alternative circuit shown in Fig. 4. It should be noted that although the two circuits have different topologies, they provide the same frequency response and are therefore equivalent for S-parameter modeling.

Similar to the RDL extraction, TSV S-parameters are converted to ABCD matrices and used to derive RLGC curves. The oxide capacitance \(C_\mathrm{ox}\), silicon-substrate capacitance \(C_\mathrm{si}\), and substrate loss resistance \(R_\mathrm{si}\) are extracted from the \(G(\omega)\) and \(C(\omega)\) curves using the same procedure as the RDL shunt-branch extraction in (7)-(9). The TSV series resistance is taken from the low-frequency value of \(R(\omega)\), while the TSV inductance is taken from the high-frequency value of \(L(\omega)\):

$$
\begin{aligned}
R_\mathrm{TSV} &= R(\omega_\mathrm{low}), \\
L_\mathrm{TSV} &= L(\omega_\mathrm{high}), \\
C_\mathrm{ox}, C_\mathrm{si}, R_\mathrm{si} &\leftarrow G(\omega), C(\omega)\ \text{using (7)-(9)}.
\end{aligned}
$$

The TSV parameter network uses `r_tsv`, `h_tsv`, and `pitch` as geometry inputs. After extracting circuit parameters for all TSV samples, an MLP learns the mapping from TSV geometry to the equivalent-circuit element values.

### 2.4 RDL-TSV Cascading Correction Model

The proposed RDL-TSV Cascading Correction Model is shown in Fig. 5. This model is inserted at each RDL/TSV junction to compensate for the parasitic effects that are not captured by directly cascading the isolated RDL and TSV compact models. It is implemented as a seven-parameter pi-type equivalent circuit. The shunt capacitance-resistance branches model local capacitive coupling and dielectric/substrate loss near the two sides of the transition, while the series resistance and inductance describe the additional transition loss, current-crowding effect, and local current-path inductance introduced by the discontinuity at the cascade interface.

Each correction model contains:

```text
Cn1, Rn1, Cn2, Rn2, Cn3, Rn3, Ln1
```

The admittances are:

```text
Y1 = j*w*Cn1 + 1/Rn1
Y2 = j*w*Cn2 + 1/Rn2
Y3 = j*w*Cn3 + 1/(Rn3 + j*w*Ln1)
```

The corresponding ABCD matrix is:

```text
A = 1 + Y2/Y3
B = 1/Y3
C = Y1 + Y2 + Y1*Y2/Y3
D = 1 + Y1/Y3
```

Compared with directly outputting the full S-parameter curve, this correction model uses a small number of circuit elements with explicit physical meaning. It can therefore improve the full-chain cascade accuracy while keeping the final model compatible with SPICE-oriented compact-model development.

### 2.5 Shared Optimization and Multi-Head Training

The full-chain structure contains twelve connection positions. If each position is trained with an independent seven-parameter network from the beginning, the model has many degrees of freedom and can suffer from non-unique optimized targets under a small dataset. The proposed flow therefore uses a staged training strategy.

In the shared optimization stage, one seven-parameter connection network is optimized for each sample and repeated at all twelve connection positions. This stage cannot represent position-dependent interface differences, but it provides a stable test of whether a compact connection correction can reduce the direct-cascade error.

In the neural-network stage, a shared MLP is first trained to map the structure parameters to the seven pi-network element values:

```text
9 -> 30 -> 30 -> 20 -> 7
```

After the shared model is trained, the connection network is expanded into a multi-head architecture. The shared trunk has the following structure:

```text
9 -> 30 -> 30 -> 20
```

The trunk is followed by twelve output heads, and each head predicts the seven pi-network parameters for one RDL/TSV junction. The resulting output structure can be written as:

```text
20 -> 7, repeated for 12 output heads
```

This two-step strategy first learns a stable shared correction and then introduces position-dependent degrees of freedom. Compared with optimizing all twelve parasitic networks independently from the beginning, it reduces target ambiguity and provides a better-conditioned training problem for the final full-chain S-parameter fitting stage.

The multi-head fine-tuning objective uses `S11`/`S21` magnitude and wrapped phase. The wrapped phase error is computed as:

```text
phase_error = angle(pred * conj(target))
```

This avoids artificial `2*pi` discontinuities that can appear when unwrapped phase values are compared directly.

For paper-style reporting, NMSE is computed on the linear real and imaginary parts of `S11` and `S21`:

$$
\mathrm{NMSE} =
\frac{\sum (y_\mathrm{true} - y_\mathrm{pred})^2}
{\sum (y_\mathrm{true} - \overline{y_\mathrm{true}})^2}.
$$

where \(y\) is formed from `Re(S11)`, `Im(S11)`, `Re(S21)`, and `Im(S21)`.

## 3. Results and Discussion

### 3.1 Verification Case and Single-Device Modeling

To verify the effectiveness of the proposed modeling method, the TSV-RDL3 case reported in [2] is selected as the validation example, as shown in Fig. 7. The structure consists of four top-metal-layer RDL sections, three bottom-metal-layer RDL sections, and six TSV sections. Therefore, the complete interconnect chain contains thirteen device sections and twelve RDL/TSV junctions.

For the RDL and TSV single-device models, 400 geometry samples are generated in their parameter spaces using Latin hypercube sampling (LHS), and their S-parameters are obtained by HFSS simulation. The equivalent-circuit parameters are extracted using the models and formulas described in Sections 2.2 and 2.3. For each circuit element parameter, an MLP with two 20-neuron hidden layers is trained to map the physical device parameters to the corresponding element value. The trained RDL and TSV models achieve average NMSE values of 0.04% and 0.02%, respectively, indicating that the single-device compact models can accurately reproduce the HFSS responses.

> **Fig. 7 placeholder.** TSV-RDL3 validation structure used to evaluate the proposed cascading correction model.

### 3.2 Cascading Correction Model Training Results

After the individual RDL and TSV device models are established, these compact models are used to replace the corresponding RDL and TSV sections in the complete structure. The replaced device sections are then connected by the RDL-TSV Transition Model, so that the full-chain circuit is constructed as a cascade of RDL models, transition models, and TSV models.

For the RDL-TSV Transition Model, 120 samples are used for training and 58 samples are used for testing. The initial parameter network uses a 30 x 30 x 20 MLP structure. The final model is expanded into a multi-head network with twelve output heads, where each head predicts the transition-model parameters for one RDL/TSV junction. Using the S-parameters of the complete cascaded structure as the target, the final full-chain model achieves an average NMSE of 3.1% on the test set.

### 3.3 Full-Chain Modeling Accuracy and Discussion

The final average NMSE of 3.1% is slightly better than the model accuracy reported in [2] using the same number of training samples.

The proposed model also has two practical advantages. First, it is more compact than a direct full-chain S-parameter neural surrogate because it only learns the parameters of physically meaningful equivalent circuits. Second, the resulting model can be implemented in a SPICE-compatible form, making it more suitable for PDK-oriented compact-model development and circuit-level verification.

Nevertheless, the optimized parasitic parameters are still obtained through a sample-wise optimization process. If several different circuit parameter sets can produce similar S-parameter responses, the supervised targets may contain ambiguity. Future work will further investigate more constrained transition-circuit topologies and parameter-regularization strategies to improve the robustness of the extracted compact-model parameters.

## 4. Conclusion

This work proposes a compact modeling method for cascaded RDL-TSV structures. By combining scalable RDL and TSV single-device models with an RDL-TSV Transition Model, the method builds an accurate high-dimensional compact model using limited full-wave data. A shared-to-multi-head training strategy reduces parasitic-parameter ambiguity while capturing position-dependent transition effects. For the TSV-RDL3 case, the model achieves 3.1% average NMSE with 120 training and 58 test samples. Since the final model is based on equivalent circuits, it better preserves passivity and causality, supports SPICE simulation, and is suitable for PDK-oriented applications.
